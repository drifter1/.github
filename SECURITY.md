# Security Policy

## Reporting a Vulnerability

If you believe you've found a security issue, please open a regular issue in this repository.

## Scope & Limitations

This is a solo-maintained project with no dedicated security team, audit, or CI security pipeline. I cannot guarantee that the project is free of vulnerabilities, and I have not performed security testing beyond what I can reasonably do on my own.

- I may not be able to respond to every report promptly.
- I may not be able to fix every reported issue.
- No security patches are guaranteed, especially for older versions.

By using this project, you accept that it is provided **as-is**, without warranty of any kind, and that you are responsible for assessing its suitability and security for your use case.
