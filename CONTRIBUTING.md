# Contributing

Thanks for your interest! This is a solo-maintained project,
so please keep the following in mind.

## Reporting Bugs

Open an issue with:
- A clear title and description
- Steps to reproduce
- Expected vs. actual behavior
- Your environment (OS, version, etc.)

## Suggesting Features

Feature requests are welcome as issues. Please describe:
- The problem you're trying to solve
- A rough sketch of how it could work

I'll do my best to prioritize, but as a solo maintainer,
not every request will be implemented.

## Pull Requests

- Fork → create a branch → commit → PR
- Keep PRs small and focused (one feature/fix per PR)
- Follow the existing code style
- I review PRs when I can, but response times may be slow
